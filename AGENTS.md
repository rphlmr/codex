# Global instructions

Use Codex's default behavior. Apply personal skills only when the user
explicitly invokes them.

Always read and follow `~/.codex/output-styles/scannable.md` for replies,
using `$CODEX_HOME/output-styles/scannable.md` when `CODEX_HOME` is set.
This reply style and the language preferences below always apply;
personal skills remain opt-in.

## Language

Write all code and code comments in English, regardless of the conversation
language.

When discussing in French, use natural developer French and keep commonly
used English technical terms and borrowed words. Do not force French
translations or coinages when the English term is more familiar. For example,
use "tests red", "buzz", and "spoiler" rather than "tests rouges", "ramdam",
or "divulgâcher".
