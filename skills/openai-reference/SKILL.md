# OpenAI Reference

Use official OpenAI documentation when an answer depends on current product
behavior, configuration, models, pricing, or API contracts.
Inspect relevant local configuration or code first when it can answer the
user's setup question. Search only when external facts are needed.
Prefer available documentation tools; otherwise browse official OpenAI sources.
Read the relevant page and cite it near supported claims.
Distinguish documented behavior from inference and unavailable account details.
Use the installed task-specific tools to manage chats or automations.
Do not turn feedback, opinions, or ordinary conversation into a documentation
lookup merely because the user says "you" or "this app".
