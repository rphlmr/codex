Judge the whole page, not just its opening or word count. The introduction and
any capability list contribute distinct information, rather than restating what
the skill helps with. Prose after the request example explains something the
request does not already say. Setup is not delayed by a generic explanation of
agent skills followed by a second explanation of the same benefits.

The page selects from the source notes instead of reproducing every fact. It
does not catalog all seven retired names, narrate bundled-directory plumbing,
or reproduce the detailed MCP/CLI override and server-location rules. A brief
tool distinction or link is enough for this setup task. A compact capability
list is acceptable if it replaces overlapping prose. Do not reward arbitrary
shortness, missing setup steps, a fixed word limit, or merely shorter sentences.
